# Сайт GarageHub

Первая версия сайта (23.10.2026). Цвета, отступы и тексты как в Mini App (`webapp/DESIGN.md`),
шрифт Onest лежит в `fonts/`, внешние сервисы не нужны. Код бота сайт не трогает.

## Как посмотреть на Маке

```bash
cd ~/Desktop/garage_bot && source venv/bin/activate && python3 site/serve.py
```

- http://localhost:8090 — настоящий каталог (нужен запущенный бот, он отдаёт данные на 127.0.0.1:8080)
- http://localhost:8090/?demo — примеры боксов, бот не нужен
- добавьте `&intro` к адресу, чтобы снова увидеть заставку, `&slow` — заставка медленно

Остановить: Ctrl+C. `serve.py` только читает открытый каталог, в базу и в Telegram ничего не пишет.

## Страницы

| Файл | Что это |
|---|---|
| `index.html` | Главная: заставка с воротами, поиск, свежие боксы, районы, как это работает, владельцам, вопросы |
| `catalog.html` | Каталог с фильтрами (тип, район, подъёмник, яма, инструмент, свободно сегодня, сортировка). Фильтры в адресе страницы |
| `garage.html?id=N` | Страница бокса: фото, цена, свободные часы на неделю, характеристики, кнопка «Забронировать» |
| `owners.html` | Для владельцев: условия, как разместить, контакты |

## Как устроено

- `css/site.css` — все стили. Светлая и тёмная тема по настройке системы.
- `js/intro.js` — заставка «ворота поднимаются» (из `logo/v2/splash-lift`). Один раз за визит, клик пропускает.
- `js/data.js` — данные из открытого API бота: `/api/garages`, `/api/garages/{id}`, `/availability`. Только публичные поля.
- `js/demo.js` — примеры боксов для `?demo`. На сайте в этом режиме висит пометка «Примеры для показа».
- `js/dom.js`, `format.js`, `icons.js` — копии из `webapp/js` (автоэкранирование, форматы цен и дат).
- Переходы между страницами — View Transitions (Chrome, Edge, Safari 18+), в остальных браузерах обычный переход.
- «Забронировать» открывает этот бокс в приложении GarageHub (`t.me/garazh_rent_bot?startapp=g<id>`).
